# 知行 - 滚动落地页设计规范 (Spec)

## 1. 概述 (Overview)
知行项目目前只有简单的单屏登录页 (`src/components/Welcome.tsx`)。本项目旨在将其扩展为一个长滚动的落地页 (Landing Page)，采用叙事感交替排版 (Storytelling) 结构，向未登录用户充分展示产品价值，提高转化率。

## 2. 页面结构与内容映射 (Page Structure)

页面整体分为 5 个区块，区块间通过滚动顺滑过渡。图文布局采用交替结构 (左图右文 -> 左文右图)，以增加视觉动感。

### 2.1 Hero 首屏 (Hero Section)
- **目的**：抓住注意力，提供直接登录入口。
- **文案**：“你收藏过的每一条干货，都欠自己两分钟。” / “无行动，不知乎”
- **视觉**：保留现有的 `Welcome.tsx` 布局，左侧文案+登录按钮，右侧为“每日宜忌日历”。
- **新增交互**：屏幕底部居中添加一个跳动的向下指示箭头 (Chevron Down)，提示用户向下滚动探索。

### 2.2 第一幕：AI 智能分拣 (AI Sorting)
- **目的**：介绍核心功能，打消用户处理几百条收藏的心理负担。
- **布局**：图左文右。
- **文案**：
  - 主标题：“收藏夹里几百篇干货？交给 AI 去挑。”
  - 副标题：“知行会帮你把长文分拣成「能做的行动」和「值得记的闪卡」。至于单纯的故事和情绪，我们会诚实地放过，绝不硬转成任务。”
- **视觉组件**：一个漏斗或流转示意图，展示带有知乎 Logo 或文章骨架的卡片，经过 AI 处理，变成干净清爽的“行动卡”和“闪卡”。

### 2.3 第二幕：每日行动与成就 (Daily Action)
- **目的**：展示产品核心体验（每天两分钟），并强调长期使用的价值感。
- **布局**：图右文左。
- **文案**：
  - 主标题：“每天两分钟，只做三件事。”
  - 副标题：“结合艾宾浩斯记忆曲线，每天为你推送最该做的事。连续打卡成功，盖上「知行合一」专属印章。”
- **视觉组件**：一张被盖上大大红色“行”字印章的行动卡片，背景可隐约透出科学复习曲线的图表轮廓，强调成就感。

### 2.4 第三幕：善意的回响 (Community Loop)
- **目的**：展示知行与知乎社区生态的良性互动，引发共鸣。
- **布局**：图左文右。
- **文案**：
  - 主标题：“让好内容知道自己被用过。”
  - 副标题：“不生产新内容，只让好内容流转。每次完成行动，一键回到知乎原贴留言。让答主收到的不再只是点赞，而是「有人真的照做了」。”
- **视觉组件**：包含输入框与“回响”按钮的留言卡片 UI 示意图，或者模拟点击后自动跳转知乎原帖点赞/评论的微交互状态。

### 2.5 底部收尾 (Bottom CTA & Footer)
- **目的**：提供最终的行动呼唤。
- **布局**：居中对齐。
- **文案**：“是时候给你的收藏夹来一次大扫除了。”
- **动作**：放置“用知乎账号登录”的主按钮 (`btn-seal` 样式)。
- **Footer**：保留原有的版权与声明。

## 3. 技术与实现要求 (Technical Requirements)
- **组件复用**：尽量复用现有的 Tailwind CSS 样式 (如 `.brush`, `.song`, `.btn-seal`, `.wall-dim`)，保持品牌调性一致。
- **响应式设计**：需要兼容移动端和桌面端。在移动端 (Mobile) 下，交替的左右图文布局应统一折叠为上下布局 (先图后文或先文后图)。
- **动效**：滚动时的简单淡入 (Fade-in) 或轻微上浮 (Slide-up) 效果（如果时间允许，否则静态展示即可）。
- **文件变更**：主要修改 `src/components/Welcome.tsx`，必要时可拆分出独立的展示组件以保持代码整洁。
